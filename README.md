# Elemental Team Builder
Неофициальный фанатский проект для подбора команд в Genshin Impact. MVP версия.

## Описание
Сайт позволяет выбрать имеющихся у вас персонажей и генерирует до 3 лучших команд на основе заложенного алгоритма, объясняя плюсы, минусы и процесс начисления баллов.

## Как открыть сайт
1. Если файлы скачаны: откройте `index.html` в браузере. (Внимание: некоторые браузеры блокируют загрузку `data/characters.json` при прямом открытии файла. Рекомендуется использовать локальный сервер или загрузить на GitHub).
2. Публикация: загрузите файлы в репозиторий GitHub и включите GitHub Pages в настройках (Settings -> Pages -> ветка main).

## Структура
- `index.html` - Каркас интерфейса.
- `styles.css` - Оформление (тёмная тема).
- `app.js` - Вся логика, фильтры и математика.
- `data/characters.json` - База персонажей.
- Markdown файлы - документация.

## Как добавить персонажа
Откройте `data/characters.json` и добавьте новый объект по шаблону существующих (описание полей в `DATA_MODEL.md`).
