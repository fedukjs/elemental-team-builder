# Архитектура проекта
- **Тип:** Статический Single Page Application (SPA).
- **Стек:** HTML5, CSS3, Vanilla JS.
- **Хранение данных:** 
  - `characters.json` подгружается через Fetch API.
  - Состояние пользователя (выбранные персонажи) сохраняется в `localStorage`.
- **Логика работы:**
  - `init()` — загрузка и рендер.
  - `renderRoster()` — отрисовка сетки с учетом фильтров.
  - `buildTeams()` — комбинаторика недостающих слотов и вызов оценки.
  - `evaluateTeam()` — ядро алгоритма оценки.
